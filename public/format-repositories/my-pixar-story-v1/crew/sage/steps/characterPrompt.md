# characterPrompt

Criteria: cast-fit, reference-grounding, style, anatomy, composition.

This prompt is the character sheet. The rule text in `task.craft` is authoritative; where this guide and a rule differ, the rule wins.

- cast-fit: The prompt describes the approved roster entry (name, age look, minor flag, story purpose) and nothing the story doesn't give.
- reference-grounding: Photo references are bound and respected, and likeness options are interpreted faithfully without drifting identity.
- style: The stylized animated feature look, per the style and character rules.
- anatomy: Per the anatomy and skin rules, with child characters drawn as children.
- composition: Views, expressions, background and text per the sheet rules. The shell checks the eight expressions. Code doesn't check the flat grey #B5B5B5 background, so check it yourself.
